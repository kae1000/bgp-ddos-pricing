## BGP 线路的溢价，什么情况下白花

BGP 干的事很具体：把电信、联通、移动几条线路合并成一条对外宣告的路径，减少跨网访问时的多层路由跳转。同一条带宽，利用率能从 40% 左右提到 80% 以上。

对国内业务来说这笔钱基本省不掉。玩家用移动宽带连你电信机房的服务器，不走 BGP 就要跨网绕路，延迟抖动肉眼可见，游戏里就是卡顿和掉线。棋牌、私服、小游戏这类既怕打又怕卡的业务，BGP 是刚需。

有两种情况，BGP 的溢价花得没意义：

**用户全在海外。** 国内多线互联解决的是国内跨网问题，对洛杉矶或法兰克福的用户没有帮助。这种业务该看的是回国线路质量（CN2 GIA 这类），不是 BGP 多线。

**访问量小到跨网损耗无关痛痒。** 日均几百 IP 的企业展示站，用户从哪个运营商来都能打开，多花的这条线路钱不如省下来。

## 攻击超过你买的档位，会发生什么

这是选购时最该问清、也最少被写进对比表的一条。行业里存在两种完全不同的处理方式。

**第一种：封 IP（黑洞）。** 攻击流量超过你买的防御值，服务商直接把 IP 拉进黑洞，所有流量丢弃，等攻击停止再解封。便宜的高防 VPS 常用这套。代价是业务中断，短的几分钟，长的几小时，取决于攻击持续多久。

**第二种：弹性升级。** 超阈值时把防御临时提到更高档位，过程中业务不中断。部分服务商支持按小时计费自动扩容，应对突发峰值。防护阈值本身也可以随时调高，不需要新增设备。

现实里还有一种混合做法。某服务商的官方说明写的是：攻击超过购买的防御阈值，系统会自动暂停该 IP，用户可以联系客服快速升级到更高防御，然后由人工解封。也就是说，"支持弹性升级"和"被打的瞬间业务不断"是两回事，前者是能力，后者是策略。

下单前直接把这几句发给客服：

> 攻击超过我买的防御值那一刻，是先封 IP 还是先自动升防？升防需要我确认吗？解封要走什么流程、大概多久？超出档位的那部分流量怎么计费？

答得清楚的，出问题时你能预估中断时长。答得含糊的，等于把业务连续性押在运气上。

**游戏服、私服、棋牌。** 高攻击风险加低延迟加三网互通，三个条件同时成立。宿迁 9950X 的高主频对 Minecraft、方舟这类吃单核的服有实际帮助。10 人以下小服，2核4G 那档（112 元/月）够跑；20–50 人在线，上 4核8G（200 元/月）；百人以上或大型模组服，得考虑 8核16G 往上的物理机。

## 几个下单前常问的问题

**100G 防御是独享还是共享？**

看价位。百元级的 150G 基本是共享清洗池，物理机档位才谈独享。要问清"清洗能力是独享还是共享，同池其他用户被打会不会影响我"。这一条比防御数字本身更影响实际体验。

**BGP 和 CN2 有什么区别？**

BGP 是多运营商互联，解决国内电信联通移动之间的跨网质量。CN2 是电信的精品国际线路，解决的是回国方向的速度和稳定性。国内业务看 BGP，出海业务或需要优质回国的看 CN2 GIA。两者不冲突，有的产品同时给。

**能不能只买防御不买服务器？**

高防 IP 或高防清洗是独立产品，可以把流量牵引到你自己已有的源站上。云厂商多数把防御和服务器打包卖，单独买高防 IP 要看具体产品线有没有开放。

**续费价等于首价吗？**

多数情况不等于。首月 5 折、年付 7 折这类优惠作用于首期，续费按标价走。下单前在订单页确认续费金额，别只看首期。
